# Photos and video

Put your own photos and a short video of the real build in this folder, then link them from the main README.
A real photo is the strongest thing in the repository, so add these:

- `arm-front.jpg`: the whole arm from the front, with a ruler or coin for scale
- `arm-side.jpg`: the side view, showing the parallelogram linkage
- `layers-close-up.jpg`: a close-up of the pivots with the glue stops
- `dry-fit.jpg`: the cardboard mock-up or the first dry fit
- `demo.mp4` (or a link to a video): the arm following the joysticks

Then add a line like this to the README, under the 3D renders:

```
![The real arm](docs/photos/arm-front.jpg)
```
