# PARALLELOGRAM-SERVO-ARM-4-SG90-MOTORS-
Hello! I've made a simple 3DOF Servo arm powered by an Arduino UNO, and 4 SG90 Motors. I did the project to try and experiment with servos, but weight became an issue so I decided to try another arrangement/linkage, and thought of using a parallelogram.  *I would like to note that I had the help of AI to build the 3D model.
